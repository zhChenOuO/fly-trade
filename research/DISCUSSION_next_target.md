### NARMA10 與 d2 的重要差異

令 `H_t=0.3y[t]+0.05y[t]Σ(k=0…9)y[t−k]+0.1`。若理想 predictor 已知道所有截至 t−1 的輸入歷史 F_(t−1)，則 H_t 與 u[t−9] 均已確定，而 u[t] 仍是獨立未知量：

`E[y[t+1] | F_(t−1)] = H_t + 0.375u[t−9]`。

不可預測的 innovation 為 `1.5(u[t]−0.25)u[t−9]`，不等於純診斷 d2；後者還把第二因子置中，整個條件期望為零。

由 Uniform[0,0.5] 可得 Var(u)=1/48、E[u²]=1/12，故即使掌握完整歷史，原主測仍有：

`MSE ≥ 1.5²·Var(u[t])·E[u[t−9]²] = 1/256`。[推導]

對應 NMSE 下限需再除以實際 target variance，這裡沒有執行資料計算，不能填入數值。DN 的可用資訊少於完整歷史，誤差可能更大。NARMA 的 y 歷史也不是實際注入 reservoir 的訊號；「它已被網路處理」不能直接當作成立。

所以原設定仍可比較兩種圖如何利用部分歷史做預測，並非所有模型都必定零能力，也不代表 Δ≥5% 絕不可能。但那是另一個帶不可觀測 innovation 的預測問題，不能用來乾淨判斷完整 NARMA 運算／非線性能力。共同誤差下限還可能壓縮相對改善；兩種圖的傳播路徑不同，也可能讓比較主要反映訊號到達時間。

**判斷：不執行原時序主測。[主觀，依上述推導]** 原 d2 的作廢，不能自動替尚未驗證的 Stage C 背書。

## Q2. 跳過能力 gate，還是修好再跑？

**選第三案：刪除目前無效的 d2 科學通過前提，保留小而直接的工程／因果驗收，然後由修正後的主測回答拓樸問題。[主觀]**

支持跳過「額外能力門檻」的理由：d1/d2 是代理任務，其門檻不保證 NARMA 表現，更不保證 real 優於 scramble。反覆替代理任務加 gate、修 gate、再校準 gate，會消耗更多人工且改變研究目標。這次已提供反例：簡化題目可以因資訊條件不同而排除一個尚未測過的主問題。

支持保留因果驗收的理由：只要原主測仍要求尚未到達 DN 的 u[t]，直接跑 21 圖只是更昂貴地重現設計限制。驗收應回答「程式真的算了預先指定、資訊可達的問題嗎」，不再要求「真圖先在另一個任務達到主觀 R² 下限」。

具體決策：

- 舊 d2 R²≥0.10、α 上界與負控制的失敗紀錄保留，不追溯改成 PASS；另以簡短修訂解除其作為新主測的前置條件。
- d1 保留為描述性能力證據；純乘積可作延遲因果 fixture 的 target，不再設真 FlyWire 必須先通過的獨立性能門檻。
- finite/state/provenance、正確 Ridge、正確 null、預先凍結 Test 與預算約束保留；Stage C 的 5% 效果 power 下界≥80%、FPR 上界≤5% 不因本次診斷錯誤而取消。
- 不照搬循環錯配 pairs 的 iid CI。新的工程 null 使用來源互不重疊的 states／target streams；它不是新增一輪真圖擇優診斷。

預算論點須更正：0.026/8=**0.325%**，不是0.03% [推導]。GPU 用量仍低，這支持一次有上限的修正；不代表人工成本也低。工作天「幾乎未用」是任務提供的估計，尚無完整人工 ledger 可核對，不能把多輪實作／審查的時間自動歸零。

## Q3. 最少需要修／驗證什麼？

**最小範圍是主測的時間契約、相同資訊條件的 fixture，以及尚缺的 C/D 接線；不重寫 simulator，不恢復 rho 搜尋，不新增替代 readout。[主觀]**

### 建議唯一目標：固定延遲 NARMA10 計算

用完整因果更新得到 `out_states[t+L]=x[t+L+1]`，重建 `y_next[t]=y[t+1]`；以歷史目標在 L 步後被讀出來定義任務。這應稱為 **delayed NARMA10 reconstruction**，不是即時預測，更不是金融預測。等待期間仍逐步接收新的 u，不重播同一輸入、不提前使用未來 state 卻聲稱即時。

**具體提案：L=9 作唯一固定候選。[主觀]** 依據是現有 d1 已顯示同一 DN 集合可恢復九步前輸入，故這個時間尺度有局部可用證據；不是證明9最佳，也不是證明 y 或18步歷史皆可恢復。正式修訂前需以非零邊的結構可達性及相同 sensory/DN 分離的 fixture 確認九步足以移除「最新所需輸入完全到不了讀出」的硬阻擋。結構可達只排除不可能，不能當成表現充分的證明。

所有 21 圖使用同一 L=9；不得逐圖選 latency、不得看 R²/Δ 後改 L。若結構／fixture 仍不成立，修正窗口停止，不臨時掃另一組 lag。圖本身的傳播速度仍是固定共同資源下的表現一部分，結論須限定於此共同 latency。

有效 target index 仍自 t=500 起，欲保留 T 個目標，模擬必須產生 500+T+L 步；使用狀態列 `[500+L:500+L+T]` 配 target 列 `[500:500+T]`。這些索引是提案的明確契約，未聲稱已實作。跨 sequence 不拼接；future u 只影響延遲後的 state，不進入 target 定義。Train、Calibration、Test 必須完全同一對齊。

最小驗收／修正清單：

1. **單邊與多跳 causal fixture。** sensory/DN 不重疊；改 u[t] 不應改當列 DN，只能在圖路徑允許的後續列出現。再核對主測 L 的切片及尾端額外步數。
2. **獨立 target oracle。** 從原始 u 與獨立 NARMA recurrence 算出 reference，和 runner 評分列逐項比對；禁止再用 target 對自己算 R²。另以可達的人工 delay／interaction feature 驗證 Ridge 接線，不能把 oracle feature 加入真圖主 predictor。
3. **同一資料規則接通 C/D。** α 僅由 Main-Train sequence CV 選，refit 後 Calibration 做既定推論校準，Test 只在凍結後建立。現有 `g1_runner` 是 callback wrapper、`g1_power` 是 residual helper，兩者存在不等於21圖完整執行端已就緒。
4. **處理已知低成本一致性問題。** Ridge exact tie-break 與 spec 對齊、float64 scaling 的數值驗收、負歷史初始化與 spec 一致；保存每 α 的 OOF loss、每序列預測誤差及 graph/input/readout/time hashes。不因 d2 失敗擴 α grid。
5. **小型端到端接線驗收。** 以 fixture 跑完 Train→Calibration→凍結→synthetic Test 的預定流程，核對1對20的 graph/sequence 推論單位、power/FPR event 和 ledger；不要求真圖先贏，也不改主要 Δ 門檻。

保留 raw u、rho=0.95、leak=0.5、1,291 DN、唯一 scramble_mixed、21圖及主要 Δ≥5%＋CI下界>0。調整只限前述時間契約與撤回無效前置 gate；不連帶改成訓練 W、CMA-ES、全腦 readout 或新增非線性 head。

因現在已看過 Diagnostic-check，不能把舊 check 改 target 後當全新確認性資料。新的 fit/check 或主測資料使用未看過表現的 streams，登錄新的 spec/source hash；原本未建立的 Main-Test 是否保留依既有治理規則另行凍結，不能以本策略文件默認其已解封。

## Q4. d1 正面結果與成功機率

**d1=0.5775 是值得繼續一次有限實驗的證據，但不是拓樸優勢證據。[既有結果＋主觀判斷]**

它支持：在既定 DN、固定 dynamics 及 fit-only Ridge 下，至少部分九步前輸入可被線性讀出；管線不是完全常數，真圖有可利用的線性記憶。它不支持：pure product 可讀、NARMA history 可完整重建、rho最佳、Ridge的所有數值細節已驗收、或真圖勝過同規模重接控制。沒有 control 的單圖 R²，不能估算 Δ。

先前5%估計混合了市場失敗、讀出衰減與對代理 gate 的假設；現在不能把無效 d2 當新的負面證據，也不能把錯誤被排除當成已找到正面拓樸效果。新的延遲主問題還改變了估計事件，不能聲稱用正式 Bayesian 更新從5%精確算成另一個百分比。

為決策提供的修正估計如下，**全部為主觀機率及主觀不確定範圍，不是資料估計或信賴區間**：

| 事件 | 主觀估計 | 解讀 |
|---|---:|---|
| 已完成因果／工程修正後，Stage C 在既定資源內滿足完整 integrity、power/FPR 條件，能進 D | 40%（20–60%） | C 尚未實測；固定模型的校準不確定性、圖完整性與人工成本仍是風險 |
| 因果正確且符合治理的延遲主測，在能完成確認性評估的條件下達 Δ≥5% 且 CI下界>0 | 15%（5–30%） | 相較先前5%上調；d1及撤除不合法負證據使繼續更合理，但尚無任何 real-vs-scramble 效果量 |

不把兩個數字當成獨立事件直接相乘，也不為「目前有缺陷的原 Stage C」報一個科學成功率。15%的判斷足以支持短修正窗口，不足以支持不停地換 benchmark。市場 Phase 0–6 的封存負面證據維持不變。

### 追問 1：共同誤差下限不使 Δ 失效

**有效，但可支持的是「固定輸入、DN 讀出、動力學與時限下的整體預測表現差異」，不是排除傳播及記憶差異後的純非線性運算優勢。** 前文從「當下輸入不可達」跳到「原主測不應執行」，缺少使比較本身失效的論證。這是我的推論過度；純 d2 的零條件期望不能套用到完整 NARMA target。

令 `m_t=H_t+0.375u[t−9]`、`ε_t=1.5(u[t]−0.25)u[t−9]`，則 `y[t+1]=m_t+ε_t`。對使用獨立訓練序列、僅依截至 t−1 資訊形成預測的任一圖 g，有 `E[ε_t | F_(t−1)]=0`，因此母體風險為：

`R_g=E[(y[t+1]−f_g)²]=1/256+A_g`，其中 `A_g=E[(m_t−f_g)²]`。[推導]

在同一 target 分布、共同 NMSE 分母下，令 `A_c=median_g(A_g)`（20 個 controls），則：

`Δ=(A_c−A_real)/(1/256+A_c)`。[推導]

共同 innovation 在風險差的分子抵消，故不改變母體優劣排序；它仍留在分母，會壓縮相對改善，**不是整個 Δ 都抵消**。所以 Δ≥5% 仍是有意義、也可能較難達到的要求，不能因有共同誤差下限就改低門檻。`1/256` 是共同不可約成分；各圖因資訊到達較晚、記憶不足或讀出受限，仍可有不同的額外誤差。

以上是母體風險分解，不保證有限樣本中的交叉項逐項消失。共同 innovation 與各模型誤差的交叉項會影響 Δ 的抽樣分布，且 innovation 的條件變異依 u[t−9] 改變。實際 sequence 聚合、median 與 CI 必須沿用凍結的 endpoint；不能把這個母體公式當成有限樣本恆等式，或拿掉序列配對及 null 校準。比較有效也不表示任意 permutation/null 都有效。

**修正後決策：保留原 `x[t+1] → y[t+1]` 對齊，撤回無效 d2 前置門檻後，完成既有工程及治理驗收即可進 Stage C，無須新增延遲或能力 gate。[主觀]** 這裡「可以進 C」是研究設計上的允許，不代表目前 callback wrapper 已有完整 C/D 執行端。仍須確認 target／state 對齊、獨立 oracle、Ridge 一致性、1 real 對20 controls 的 null、共同序列相依、封存資料與預算；C 的 power 信賴下界≥80%、FPR 信賴上界≤5% 及 D 的 Δ≥5%＋CI下界>0 均保留。

工程驗收應證明程式符合指定的資訊限制，不能再要求每個 target 因子必須當下可見，否則又把可合法研究的預測問題誤判為無效。若 C 因共同 innovation 造成的變異而未達 power 門檻，應按既定規則 no-go，不能藉此再挑延遲或放寬效果量。前文針對延遲任務提供的主觀成功機率也不直接移用到原任務。

### 追問 2：L=9 沒有建立等效傳播條件

**(a) 只提出最低可達性驗收，沒有驗證全部21圖在 L=9 時的影響力已穩定或等效。** 前文的 fixture 只擬排除完全不可達，連這項驗收也尚未執行。real 的 d1 lag9 結果不能證明 controls 的傳播速度、混合程度或非線性資訊保留程度相同；可達路徑也不保證有足夠有效權重或可讀出訊號。

**(b) 同意固定 L 不能隔離傳播速度，但不同意它必然使整體表現比較不公平，或這個差異只由延遲方案新引入。** 原時序也有圖間傳播差異。若估計的是固定資源／時限下的整體拓樸效果，傳播速度是拓樸作用的一部分；若聲稱估計「排除傳播差異後的非線性品質」，現有設計確實無法識別該命題。前者不用先把每張圖變成相同傳播速度，後者則需要額外的機制對照，不能靠共同 L 自動成立。

L=9 提案另有具體的選擇風險：候選值來自已看過的 real-only 記憶結果，而不是預先獨立制定的共同時間預算。這不證明 L=9 必定偏袒 real，卻不足以宣稱公平性已驗證。也不能未經量測便斷言本專案的 degree-preserved scramble 一定傳得更快。

「再選更長 L，等所有圖收斂」不是可靠補救。持續接收 iid 輸入的 recurrent 系統，單次 u[t] 的影響可能先傳播、再混合、最後衰減；並無已證明的共同時間點能保證各圖都保存同樣充分的資訊。影響力都衰減到零，也不是資訊充分性的收斂。逐圖選最佳 L 會改成不同時間資源下的比較；看結果後選共同 L，則增加選擇自由度。

**(c) 撤回 L=9，保留原時序與單一整體表現命題。[主觀]** 不加 latency 搜尋、不加「全圖收斂」gate，也不把主要指標改成傳播速度。主結果限於本輸入／讀出及固定動力學下，real 是否比指定 scramble ensemble 有更低預測誤差；不得直接推論純非線性運算較佳、所有任務皆有拓樸優勢，或失敗代表拓樸普遍無關。

對這個整體表現命題，**不需要額外的傳播匹配控制作為 Stage C 前置條件**。若另要拆解機制，可用所有21圖同一規則的路徑／擾動傳播描述作輔助，不能據此挑 L、刪 controls 或改主要門檻。若堅持主張排除傳播差異後的非線性優勢，則需要另行預先註冊可識別該效應的對照設計；僅補一張影響力曲線仍不足以支持該因果歸因。這不是本次 G1 繼續執行的必要新增工作。
